# _2026_Pedersen_HPRT_activity
Scripts and output from "Massively parallel functional assessment of HGPRT variants reveals residual activity among pathogenic alleles" by Line Pedersen, Kristoffer E. Johansson, Douglas M. Fowler, Kresten Lindorff-Larsen and Rasmus Hartmann-Petersen

[Preprint (soon to be available)](https://doi.org/)

Contents
--------
* **illumina**: Scripts for calculating the abundance
* **score**: Scripts and output for making MAVE scores
* **plots**: 

The final scores are also deposited at [MAVEDB](https://www.mavedb.org/) under URN mavedb:000...

Illumina sequencing reads are available at [ERDA](https://sid.erda.dk/sharelink/hJLtdDBqb9)  (later https://doi.org/10.17894/ucph....)

FASTQ files are also deposited at [NCBI SRA](https://www.ncbi.nlm.nih.gov/sra) under BioProject ID: PRJNA1277552
